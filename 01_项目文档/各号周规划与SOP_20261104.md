## 二、SOP标准操作流程（从素材进来到发布）

### 阶段0：素材进来，先整理分类

**店家把素材传过来后：**

1. **检查素材质量**
   - [ ] 打开素材文件夹，数数量
   - [ ] 看清晰度，模糊的剔除
   - [ ] 看是不是同一款产品多角度

2. **按产品系列分组**
   - [ ] 双拼套装（恩施玉露+利川红）
   - [ ] 利川红系列（红袋/红罐）
   - [ ] 楚汉茶礼（浅金盒/三罐）
   - [ ] 其他新品（单独标记）

3. **给每张图打角度标签**
   - [ ] 手提袋（正面/侧面）
   - [ ] 合盖礼盒（正面/俯视）
   - [ ] 开盖（红青罐/三罐）
   - [ ] 全开（平铺/展示）
   - [ ] 人物手持（手拿/托举）

4. **规范命名，存到素材库**
   - [ ] 命名规则：`产品缩写_角度_序号.jpg`
   - [ ] 例：`lp_hou_01.jpg`（利川红_手提袋_第1张）
   - [ ] 存到 `03_素材\高清素材\` 对应文件夹

---

### 阶段1：分配素材到各个号

**根据各号定位分配：**

| 账号 | 主打产品系列 | 素材分配逻辑 |
|---|---|---|
| 主号 | 全系列（品牌展示） | 用最好看的礼盒图，高端感 |
| 黄鹤楼店 | 利川红 + 双拼 | 游客买得多的两款，多选 |
| 街道口店 | 双拼 + 冷泡茶 | 学生喜欢的平价款 |
| 武大店 | 双拼 + 小礼盒 | 学生预算，小份装 |
| 司门口店 | 利川红 + 老字号款 | 长辈喜欢的红茶 |
| 江汉路店 | 楚汉茶礼 + 颜值款 | 年轻人喜欢的好看盒子 |
| 东湖店 | 全系列（季节限定） | 春游/秋游主题搭配 |
| 小宇 | 全系列（测评向） | 多拍几款做对比 |

---

### 阶段2：按主题生产内容（每个号每篇笔记）

**步骤1：选题**
- [ ] 从周规划表里选这周要发的主题
- [ ] 确定核心关键词（1个）
- [ ] 确定产品系列（双拼/利川红/楚汉）
- [ ] 确定人设口吻（学生/上班族/宝妈/本地人等）

**步骤2：选素材**
- [ ] 从素材库选4张同系列产品的多角度图
- [ ] 必须：手提袋/合盖/开盖/全开 各一张
- [ ] 确认图片清晰、角度不重复

**步骤3：做封面**
- [ ] 打开 `05_处理脚本\make_cover6.py`
- [ ] 修改标题文字（第一行+第二行，突出主题）
- [ ] 运行脚本生成拼图封面
- [ ] 检查：字体黑体粗描边、感叹号红色、四宫格对齐

**步骤4：写文案**
- [ ] **标题：** 前10字含核心大词，结构=核心大词+长尾词+场景+钩子
- [ ] **正文开头：** 3行内出现1-2次核心词，用具体人物场景（匹配人设）
- [ ] **正文中间：** 👉符号列表写3个卖点，自然融入场景词
- [ ] **正文结尾：** 二次强化核心词 + 同城引流（📍门店+评论区互动）
- [ ] **标签：** 10个（2核心+3长尾+3场景+2同城）

**步骤5：上传发布**
- [ ] 打开创作中心 `https://creator.xiaohongshu.com/publish/publish`
- [ ] 切到"上传图文"
- [ ] 第1张传拼图封面
- [ ] 第2-5张传4张原图
- [ ] 填标题、正文、标签
- [ ] **检查无误后，用户自己点发布**（风控红线）

**步骤6：发布后**
- [ ] 记录发布时间、主题、核心词
- [ ] 评论区用小号自问自答（埋长尾词）
- [ ] 观察24小时数据（曝光/点赞/收藏）

## 三、发布节奏控制（避免限流）

| 规则 | 要求 |
|---|---|
| 每个号发布频率 | 每周3-4篇，不要每天发 |
| 发布时间 | 错峰：早9点/午12点/晚6点，轮流来 |
| 多号同时发 | 间隔至少2小时，不要同一时间发 |
| 内容差异化 | 每篇主题不同、人物场景不同、文案不重复 |
| 账号人设 | 每个号锁定一种人设，不要混着来 |

## 五、风控红线（绝对不能碰）

1. **不能AI全托管代发**——最后一下"发布"必须人点
2. **不能刷赞刷评论**——会限流
3. **不能硬广导流**——不能写"加微信""私信我"
4. **不能批量发**——一号一天最多1条
5. **十几个号不能同时发**——错峰，间隔2小时
6. **不能复制粘贴**——每篇必须重写，不能换人称就发
