## 三、核心工程 jcs_auto 使用说明

### 目录结构

```
jcs_auto/
├── src/                    # 六个核心模块 + 主入口
│   ├── asset_lib.py        # 素材库：树状目录自动创建、SHA-256 图片指纹、已用图去重
│   ├── image_pipeline.py   # 拼图配字：4 套模板（四宫格/九宫格/单图大字/系列化拼图），输出 1080×1440 3:4 封面
│   ├── copy_engine.py      # 文案引擎：4 场景标题公式库、5 段式正文、账号差异化、广告法敏感词过滤
│   ├── scheduler.py        # 调度器：确定性错峰算法（间隔≥30 分钟，数学保证），15 账号验证通过
│   ├── risk_control.py     # 风控引擎：每日≤1条、时段限制、图片去重、文案相似度≥60%拦截、失败率≥20%熔断3小时
│   ├── publisher.py        # 发布器：Playwright 多账号独立 user_data_dir+代理，登录校验→传图→填文→发布
│   └── main.py             # 主入口：--dry-run 预演 / --wait 定时到点发布 / 立即发布
├── config/
│   ├── config.example.json # 账号/代理/环境示例
│   └── copy_templates.json # 文案模板
├── assets/                 # 素材库（01_产品线/02_场景/03_文字素材/04_成图输出/05_已用图）
├── output/                 # demo 模板样例图、logs 运行日志
├── tests/                  # 3 个测试文件（run_all.py 一键跑）
├── README.md
└── requirements.txt
```

### 运行与验证命令

```bash
# 1) 单元测试（17 项，全部通过为正常）
python tests\run_all.py

# 2) 端到端预演（不真正发布，生成差异化文案 + 错峰时间 + 系列化封面）
python src\main.py --dry-run

# 3) 正式发布-定时模式（长驻等待，按排期到点发布；需先配置 config、安装 playwright 并登录账号）
python src\main.py --wait

# 4) 正式发布-立即模式（生成完即发，适合部署端系统定时任务每天跑一次）
python src\main.py
```

## 附：风险与坑（已发现，勿重踩）

- **发布器依赖 Playwright**：当前环境未安装时会提示部署指引；正式发布前需安装并完成账号登录态配置（登录态失效需人工扫码）

## 七、接手修复记录（2026-10-28 新增）

> 接手验证时发现 3 个会影响试点成败的隐患，已全部修复并验证。**本次修改仅改动桌面副本 `jcs_auto`，未动原主目录工程。**

### 发现的问题（实测与清单原记录不符）

1. 同批两个账号 dry-run 时**标题完全相同**（原设计用 Python 内置 `hash()` + 随机挑模板，跨进程不稳定且可能撞车）
2. **两张封面图 MD5 完全一致**（同一批素材 + 同一模板 → 同一张图，小红书会判重复）
3. 风控的**文案相似度 ≥60% 拦截未接入主流程**（`check_copy` 定义了但 `build_daily_pack` 未调用）

### 修复内容

| 文件 | 改动 |
|---|---|
| `src/copy_engine.py` | `make_headline`/`make_body` 新增 `variant` 参数：不同账号强制错开标题模板、开头词、标签子集、卖点顺序；新增 `core_text()` 提取可变核心供相似度比对（门店/引导语等品牌固定段不计入） |
| `src/main.py` | ① seed 改为「日期+账号序号」确定性值（跨进程稳定）；② 队列内素材 hash 互斥，素材不足自动跳过并提示；③ 相似度校验接入主流程（比对可变核心，≥60% 拦截） |
| `src/asset_lib.py` | `pick_unused` 新增 `exclude` 参数（本批队列互斥选图） |
| `config/config.example.json` | 新增 `points_sets` / `use_scenes` 多组卖点与场景句，账号间轮换（商家素材到位后可扩充） |
| `tests/test_risk_control.py` | 修复 `test_frequency_daily_limit` 时间耦合：原用写死日期 `2026-10-27` 读状态，跨天后必挂，改为动态当天 |
