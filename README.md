# 江陈记茶业 · 小红书多账号自动发布系统

给「江陈记茶业」做的一套小红书内容自动化：**素材整理 → 拼图配字 → 写文案 → 多账号定时发布 → 风控**。

2026-10 移交版：核心工程开发完成（17 项单测 + 端到端 dry-run 通过），等商家素材与试点账号，进入试点验证。

## 核心工程 jcs_auto

Python 3.13 + Pillow。六大模块：`asset_lib`（素材库与去重）、`image_pipeline`（4 套拼图模板）、`copy_engine`（4 场景文案）、`publisher`（多账号发布）、`risk_guard`（风控）、`scheduler`（调度）。

```bash
pip install -r jcs_auto/requirements.txt
python jcs_auto/src/main.py --dry-run    # 不真发，走一遍全流程
```

发布依赖账号 cookie，放在 `jcs_auto/config/` 下（仓库里只留 `config.example.json`，真配置不进 git）。
